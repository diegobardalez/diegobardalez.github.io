# diegobardalez.github.io

Página personal de Diego Bardalez — Offensive Security Engineer / Red Team Operator / Pentester.

Sitio estático (HTML, CSS y JS puro, sin frameworks ni build step) publicado con GitHub Pages.

## Desarrollo local

Sirve la carpeta con cualquier servidor estático, por ejemplo:

```bash
python -m http.server 4173
```

Luego abre `http://localhost:4173`.
